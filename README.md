# Площадь круга — практическая работа 2.2, задание 2

Интерактивный эксперимент с разбиением круга на равные секторы и их перестановкой.

## Запуск без интернета

1. Откройте [index.html](./index.html).
2. Нажмите кнопку Download raw file (скачивание исходного файла). Можно также выбрать Code → Download ZIP и распаковать архив.
3. Откройте скачанный index.html в браузере.

Никаких дополнительных программ, библиотек, аккаунтов или интернет-соединения не требуется после скачивания.

## Возможности

- 4, 8, 16, 32, 64 или 128 секторов.
- Плавное преобразование и ручное управление ползунком.
- Изменение радиуса и числовых расчётов.
- Сравнение длины хорд и предельных размеров.

Эксперимент иллюстрирует гипотезу S = πR², но не заменяет доказательство. Промежуточные положения секторов являются схематической анимацией.
