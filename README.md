## Запуск без интернета

Выберите Code → Download ZIP, распакуйте архив целиком и откройте index.html. Обе страницы связаны относительными ссылками. Интернет и внешние библиотеки не требуются.

Задание № 2 содержит модель перестановки секторов. Задание № 3 содержит доказательство методом исчерпывания, интерактивное сравнение многоугольников, последовательность записей и трёхколоночную технологическую карту на 45 минут. Карту можно распечатать или сохранить в PDF через браузер.

Эксперименты иллюстрируют математические закономерности, но не заменяют доказательство.
